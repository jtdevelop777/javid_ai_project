ติดปัญหานิดหน่อยที่ Mirror (เซิร์ฟเวอร์เก็บไฟล์) ในไทยครับจักร์ชัย! ดูเหมือน mirrors.cloudforest.co.th จะไม่ตอบสนอง (Connection timed out) ทำให้เราโหลด lm-sensors ไม่ผ่าน

ไม่ต้องตกใจครับ นี่คือเรื่องปกติของ Linux เราแก้ได้ง่ายๆ ด้วยการเปลี่ยนไปใช้ Mirror มาตรฐานของ Ubuntu หรือตัวที่เสถียรกว่าครับ

🛠️ วิธีแก้ไข (Step-by-Step)
1. ลอง Update ล้างท่อดูก่อน:
บางทีแค่การ Update ใหม่เพื่อให้มันไปหา Route อื่นอาจจะช่วยได้

Bash
sudo apt update --fix-missing
2. เปลี่ยน Mirror (ถ้าข้อ 1 ยังไม่ได้):
ถ้ามันยังพยายามจะไปที่ cloudforest แล้วค้าง ให้เราเปลี่ยนไปใช้ Mirror หลักครับ:

เปิดไฟล์ sources.list:

Bash
sudo nano /etc/apt/sources.list
มองหาบรรทัดที่มีคำว่า mirrors.cloudforest.co.th แล้วเปลี่ยนเป็น archive.ubuntu.com หรือ mirror1.ku.ac.th (ของ ม.เกษตร เสถียรมากครับ)

กด Ctrl+O เพื่อ Save และ Ctrl+X เพื่อออก

3. ติดตั้งอีกครั้ง:

Bash
sudo apt update
sudo apt install lm-sensors

psensor

ขั้นตอนการแก้ปัญหา (Step-by-Step)
1. สร้างไฟล์แหล่งเก็บซอฟต์แวร์ใหม่
เราจะสร้างไฟล์ ubuntu.sources ให้มีเนื้อหาที่ถูกต้อง (สำหรับ Ubuntu Noble 24.04 หรือเวอร์ชันที่คุณใช้อยู่) โดยใช้คำสั่งนี้ครับ:

Bash
sudo nano /etc/apt/sources.list.d/ubuntu.sources

1. ติดตั้ง LibreOffice (มาตรฐานของสาย Linux)
LibreOffice เป็นชุดออฟฟิศที่ได้รับความนิยมสูงสุดใน Linux และรองรับการทำงานกับ Python ได้ดีมากครับ กัปตันสามารถติดตั้งผ่าน Terminal ได้เลยแม้ไม่มีเน็ต (ถ้ากัปตันโหลดไฟล์ .deb หรือ .rpm เตรียมไว้ล่วงหน้า):

คำสั่งติดตั้ง (ถ้ามีเน็ตชั่วคราว): sudo apt install libreoffice

การทดสอบกับ Python: กัปตันสามารถใช้ Library อย่าง python-docx (สำหรับไฟล์ .doc) หรือ pandas / openpyxl (สำหรับไฟล์ .xlsx) สร้างไฟล์ขึ้นมา แล้วใช้ LibreOffice เปิดเช็คความเนียนของฟอร์แมตได้ทันทีครับ

ข้อดี: มันทำงานแบบ Offline ได้สมบูรณ์ และจัดการไฟล์ตระกูล .docx, .xlsx, .pptx ได้แม่นยำมาก

คำสั่งติดตั้ง: sudo snap install onlyoffice-desktopeditors (หรือโหลดไฟล์ติดตั้งแบบ Offline มาลงครับ)
